Read `AGENTS.md` before starting.

We need install and config react redux toolkit

install and config

- `@reduxjs/toolkit`
- `react-redux`

Create a redux `store.ts` file in `src/store`

Config and create api service

- create folder `src/store/service`
- add sample get api using any dummy api
- config it in `store.ts` file
- Wrap `App` component with redux provider and set the store props

### Check when done

- All libraries related redux, react redux installed
- Properly config react redux query to use the get api
- verify `es-lint` pass
- verify `npm run build` succes
